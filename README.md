
# 👗 Fashion Store

A full-stack Fashion Store web application that allows users to browse fashion products, manage their shopping cart, and place orders through a modern and responsive interface. The project is built using the MERN stack, providing a seamless shopping experience with secure backend APIs and dynamic frontend interactions.

---

## 🚀 Features

- 🛍️ Browse fashion products
- 🔍 Search and filter products
- 👤 User Authentication (Login & Registration)
- ❤️ Wishlist support
- 🛒 Shopping Cart
- 💳 Secure Checkout
- 📦 Order Management
- 📱 Fully Responsive Design
- ⚡ REST API Integration

---

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Prasannkumar279/Fashion-Store.git
```

### 2️⃣ Navigate to the Project

```bash
cd Fashion-Store
```

### 3️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

### 4️⃣ Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5️⃣ Configure Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 6️⃣ Run the Backend

```bash
cd backend
npm start
```

### 7️⃣ Run the Frontend

```bash
cd frontend
npm start
```

The application will run on:

- Frontend: http://localhost:3000
- Backend: http://localhost:5000
